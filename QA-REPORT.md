# Test report / Отчёт об испытаниях

[English test coverage](docs/en/testing.md) | [Проверка на русском](docs/ru/testing.md)

The first public release retains the accessibility code checked with 88 unit tests and 254 live scenarios in NVDA. Release packaging has additional tests for offline language links, reproducibility and exclusion of private diagnostics. Live tests used the Russian PowerManagerII 4.1 revision 646, NVDA 2025.3.3 32-bit and Windows 11 25H2.

The linked reports describe the actual checks and their limits. Raw workstation logs, vendor binaries and personal configuration are excluded from the repository and release archives.

Первый публичный выпуск сохраняет код доступности, проверенный 88 модульными тестами и 254 сценариями в работающей NVDA. Для подготовки выпуска добавлены тесты языковых ссылок, повторяемости архивов и исключения личной диагностики. Испытания интерфейса проводились на русской PowerManagerII 4.1 revision 646, NVDA 2025.3.3 32-разрядной и Windows 11 25H2.

В отчётах по ссылкам описаны выполненные проверки и их границы. Исходные журналы, файлы производителя и личные настройки не входят в репозиторий и архивы выпуска.
