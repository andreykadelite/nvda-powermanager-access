# Changelog

## 1.0.0 - first public release

Read UPS status and measurements with descriptive labels. Choose tabs with Enter or Space, and use menus, settings, notifications, history and task schedules from the keyboard. Measurement history has a text reader with 50 records per page. Supported equipment and deletion commands require confirmation when used through the add-on.

The interface is Russian. English and Russian user guides, developer instructions and test coverage are included. Exact live-graph points remain unavailable through the vendor control; current measurements and saved history can be read separately.

Earlier version numbers were private development builds and are not public releases. See [release notes](docs/release-notes.md).

## По-русски

Версия 1.0.0 начинает публичную историю проекта. Дополнение читает состояние и показания ИБП, открывает вкладки по Enter или пробелу, даёт доступ с клавиатуры к меню, настройкам, оповещениям, истории и расписанию. История измерений читается по 50 записей. Поддерживаемые команды оборудования и удаления требуют подтверждения при выполнении через дополнение.

Интерфейс русский. Инструкция пользователя, руководство разработчика и описание испытаний есть на двух языках. Точные точки графика остаются недоступны через компонент производителя; текущие значения и сохранённая история читаются отдельно.
