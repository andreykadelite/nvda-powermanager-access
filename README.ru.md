# PowerManagerII Access

[English](README.md) | [Инструкция](docs/ru/user-guide.md) | [Разработка](docs/ru/development.md)

PowerManagerII Access помогает работать с Richcomm PowerManagerII через NVDA. PowerManagerII следит за источником бесперебойного питания (ИБП) и управляет им. Дополнение подписывает элементы программы, добавляет управление с клавиатуры и выводит показания ИБП в виде текста.

Первый публичный выпуск имеет номер **1.0.0**. Названия элементов и окна дополнения русские. Инструкция и материалы для разработчиков доступны на русском и английском; английского интерфейса в этом выпуске нет.

## Возможности

- Чтение состояния связи с ИБП, заряда, нагрузки, напряжения, частоты и остальных показаний программы.
- Ручное открытие вкладок. Стрелки перемещают фокус, Enter или пробел открывает вкладку, Tab переводит к данным.
- Доступ с клавиатуры к меню, настройкам, оповещениям, расписанию задач и журналам.
- Текстовая история измерений по 50 записей с минимумом и максимумом значений на странице.
- Сообщения об изменении состояния ИБП по желанию пользователя.
- Подтверждение поддерживаемых команд питания, тестирования, расписания и удаления при выполнении через дополнение.

График не передаёт NVDA числовые точки. Для чтения предусмотрены текущие измерения и отдельная сохранённая история.

## Установка

1. Скачайте `powerManagerAccess-1.0.0.nvda-addon` из раздела [Releases](../../releases/latest).
2. Откройте файл, подтвердите установку и перезапустите NVDA.
3. Откройте PowerManagerII и нажмите `F6`. NVDA перейдёт к данным текущего экрана.
4. Нажмите `Control+Tab`, чтобы перевести фокус на другую вкладку. Откройте её клавишей `Enter`, затем нажмите `Tab` для чтения.

Стрелки читают строки, `F5` обновляет данные и сохраняет позицию. `Escape` возвращает в PowerManagerII. Для использования дополнения Python не нужен.

## Проверенная среда

| Компонент | Версия |
| --- | --- |
| PowerManagerII | Richcomm 4.1 revision 646, русский интерфейс |
| Версия файла PowerManager.exe | 1.0.348.273 |
| NVDA | 2025.3.3, 32-разрядная |
| Windows | Windows 11 25H2 |

В манифесте указаны минимальная версия NVDA 2025.3 и проверка на серии 2025.3. Другие сборки PowerManagerII и более новые версии NVDA требуют отдельной проверки. Подробности есть в [отчёте об испытаниях](docs/ru/testing.md).

## Сборка и участие

В Windows с Python 3.11 или новее выполните:

```powershell
.\tools\bootstrap.ps1
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\build.py
```

В папке `dist` появятся дополнение, архив исходников и контрольные суммы SHA-256. [Руководство разработчика](docs/ru/development.md) описывает зависимости, устройство кода и выпуск новой версии. Ошибку можно сообщить через [форму обращения](../../issues/new/choose).
